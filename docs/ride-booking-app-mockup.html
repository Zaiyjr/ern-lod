UI Mockup · Ride Booking

Five screens, one ride

A rider app concept in the dark-map theme — request, match, meet the driver, ride, and pay. Everything below is one self-contained file: the map, the icons, and the phone chrome are all inline SVG. It is also wired as a click-through prototype: tap a primary action to move through the flow.

  • 390 × 844 frames
  • Poppins + Open Sans
  • #0F172A base
  • #2563EB accent
  • 8pt rhythm
  • 44–52pt targets
  • Tap-through prototype

Design system — Swiss minimalism, Poppins 600 / Open Sans, accent #2563EB on base #0F172A, 8pt spacing rhythm, 44–52pt touch targets, 26px bottom-sheet radius. Blue text uses #60A5FA (7.0:1) because the raw accent only reaches 2.7:1 as text on this background.

Prototype wiring — primary actions advance (01→02→03→04→05), back arrows and Cancel return to the previous screen, matching and the ride itself complete on their own after a few seconds, and finishing the ride loops back to the start. The right/left arrow keys step through the flow when a screen is focused.
